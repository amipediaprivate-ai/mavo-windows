# 视觉相似、预览适配器与自适应缩略图

## 视觉特征

图片、动图首帧与 PSD 合成图在生成缩略图时只解码一次，同时计算：

- 64 位 dHash：将图像缩放为 9×8 灰度图并比较相邻像素，使用汉明距离排序相似度。
- 三色调色板：在 96×96 采样图上按 RGB 量化分桶，过滤低透明度像素并选择颜色距离足够大的三个主色。

特征存入 `asset_visual_features`，通过 `asset_uid` 关联资源，另存 `modified_ms` 和算法版本。资源内容时间变化或资源删除时，数据库触发器会删除旧特征。列表查询只读取与当前 `modified_ms` 一致的调色板。

“查找相似”默认返回 dHash 距离不超过 18 的前 24 项。结果显示相似百分比、格式和缩略图。dHash 适合构图近似和缩放/轻微调色后的图片，不等同于语义检索。

## 预览适配器

`PreviewAdapter.tsx` 按资源能力选择渲染器，弹窗不再包含格式分支：

- 图片：现有安全解码与原图读取。
- PDF：PDF.js worker 分页绘制到 Canvas。
- 字体：`FontFace` 临时加载 TTF、OTF、WOFF、WOFF2，关闭预览后卸载。
- 3D：Three.js 支持 GLB/GLTF、OBJ、FBX、DAE、3DS、STL，并提供轨道旋转、缩放和自动取景。

本地文件仍通过按数据库 ID 查询的 `caevir-media` 协议读取，不向前端暴露任意文件路径。严格 CSP 仅为该协议、字体资源和同源 PDF worker 增加白名单。GLTF/OBJ 的外部纹理或伴随文件尚不自动解析，优先使用内嵌资源的 GLB。

## 自适应缩略图调度

每批任务根据 `available_parallelism`、待处理文件类型、文件大小和最近用户交互动态决定 1–4 个工作线程：

- 交互后 2.5 秒内固定单线程。
- 音视频、PSD/PSB/TIFF/EXR/HDR 或 96 MiB 以上文件固定单线程。
- 32 MiB 以上普通文件最多双线程。
- 轻量图片使用 `CPU - 1`，上限四线程。

SQLite 写入仍以八项事务批量提交；媒体处理继续受全局锁保护，避免多个 FFmpeg 任务竞争资源。

## 验证重点

- dHash 稳定性、调色板抽取、特征持久化与修改失效。
- CPU/交互/重文件条件下的工作线程策略。
- PDF worker、字体和 3D 资源只能通过受限本地协议读取。
- CSP 不允许通配符或 `unsafe-eval`。
